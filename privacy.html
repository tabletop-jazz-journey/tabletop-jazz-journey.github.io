Privacy Policy

Last updated: October 9, 2026

This Privacy Policy explains how the "Tabletop Jazz Journey Automation" tool (the "Tool") handles data. The Tool is a private application used only by the owner of the Tabletop Jazz Journey YouTube channel to prepare, upload and manage videos on that channel and to review the channel's performance. It is not offered to other users.

Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Data accessed through YouTube API Services is also subject to the Google Privacy Policy.

Information the Tool accesses

  • Basic information about the channel owner's own YouTube channel (such as the channel name and ID).
  • The channel's own videos, playlists and thumbnails, in order to upload and update them.
  • Aggregated performance data for the channel's own videos (such as views, watch time and click-through rate) from YouTube Analytics.

The Tool does not access data about other YouTube users, and it does not collect personal information from viewers.

How the information is used

The information is used only to publish videos on the channel and to plan future videos based on the channel's own performance.

Storage and sharing

  • Authorization tokens are stored securely on the channel owner's own computer or in encrypted secrets of the channel owner's private automation environment.
  • Performance data is stored only as aggregated summaries for planning purposes.
  • The information is not sold, rented or shared with third parties.

Revoking access

Access granted to the Tool can be revoked at any time from the Google security settings page. When access is revoked, stored authorization tokens are deleted.
